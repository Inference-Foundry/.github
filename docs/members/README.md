# Members

Inference Foundry keeps a **private** repository for the member handbook and **canonical roster** so operational detail stays easy to find without mixing it into every product repo.

## Organization members

If you have access, open **[Inference-Foundry/.github-private](https://github.com/Inference-Foundry/.github-private)**:

| Document | Purpose |
|----------|---------|
| [`README.md`](https://github.com/Inference-Foundry/.github-private/blob/main/README.md) | Members handbook — onboarding, links, where to change what |
| [`TEAM.md`](https://github.com/Inference-Foundry/.github-private/blob/main/TEAM.md) | Roster, founders, project leads |

Request access from an existing org owner if you cannot view that repository.

## Everyone else (public)

- **Organization profile:** rendered from [`profile/README.md`](https://github.com/Inference-Foundry/.github/blob/main/profile/README.md)
- **Project summaries:** [`docs/projects/`](../projects/README.md)
- **Policies:** [CONTRIBUTING.md](https://github.com/Inference-Foundry/.github/blob/main/CONTRIBUTING.md), [CODE_OF_CONDUCT.md](https://github.com/Inference-Foundry/.github/blob/main/CODE_OF_CONDUCT.md), [SECURITY.md](https://github.com/Inference-Foundry/.github/blob/main/SECURITY.md)
