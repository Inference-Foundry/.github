# Crucible

Open-source **research journal and experimental log** for the organization: writeups, experiment notes, and reproducible procedures tied to LLM, diffusion, and systems work—separate from the low-level engineering bar of [super-ollama](super-ollama.md).

## Links

- **Repository:** [github.com/Inference-Foundry/Crucible](https://github.com/Inference-Foundry/Crucible)
- **Issues / PRs:** use the Crucible repo for journal entries, corrections, and discussion.

## How to help

Contribute in the form that repository defines (e.g. structured posts, lab notes, or linked artifacts). This is not the same contribution model as the CGo/Go inference stack: follow Crucible’s own `CONTRIBUTING` when it exists, or open a discussion issue to align on format.
